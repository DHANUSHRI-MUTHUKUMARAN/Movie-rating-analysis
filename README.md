# Movie Rating Analysis & Recommendation System

## Project Overview

This project analyzes the MovieLens dataset to understand movie ratings, genres, and audience preferences. It also includes a sentiment analysis of movie tags and a collaborative filtering recommendation system built using SVD.

---

## Features

- Exploratory Data Analysis (EDA)
- Feature Engineering
- Rating & Genre Visualizations
- Genre Trend Analysis
- Sentiment Analysis using TextBlob
- Movie Recommendation System using SVD
- Interactive Streamlit Dashboard
